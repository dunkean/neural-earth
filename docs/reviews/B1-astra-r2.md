## First-round corrections

- **Astra B1-R1-01 resolved for the intended export workflow.** CPU conditioning is identified as `cpu-conditioning`. `neural_manifest()` reads the configured execution profile and current inference version, removes the free-memory label, records actual checkpoint kwargs/precision/device capability, and checks the selected world profile. NN and CPU artifacts occupy separate world-hash paths. NPZs embed world/seed/ablation/exporter identity; metrics bind their file digest and numerical profile. `_read_artifact()` verifies current source/model bytes, manifest identity, NPZ identity/digest, NN profile and native focus before report construction. The regression distinguishes batch-16/batch-8 identities and rejects mixed/altered products.
- **Astra B1-R1-02 resolved.** Every context summary now has explicit bounds, shape and physical cell size. The report calls these different-footprint distributions. A separate matched-footprint diagnostic interpolates conditioning/coarse/latent physical elevations at DEM pixel centers, and the report explicitly disclaims native 30 m information in those interpolated fields. Cross-ablation DEM comparison checks common bounds and dimensions.
- **Opus A1 coupling concern addressed by a defined experimental change.** A1 substitutes macro elevation into the raw natural stack before `finalize`, recomputing natural temperature lapse and BIO4 coupling. The corresponding CPU test checks that exact contract. A2 retains A0 elevation; A3 remains a combined geography/climate experiment. The old A1 physical-climate-preservation interpretation no longer describes v2.
- **Opus climate-support concern addressed by an explicit measured policy.** A2/A3 climate is clipped per channel to A0 physical extrema on a fixed seed-specific 256×128 global calibration lattice. Diagnostics report pre/post-clip fractions and checkpoint z-scores. This resolves the absence of a declared bound; it does not establish the training distribution's full support or validate multivariate/polar climate quality. The documented roughly 20.6% seed-zero A3 BIO1 preclip fraction is correctly treated as a limitation.
- **Visual diagnostic tooling materially improved.** The default DEM crop is now 256²; three selected cases request 1024². Default focus is a cell center, explicit corpus focuses are preserved, latent context expands with the DEM, the fixed palette extends to 9,000 m, and fixed-light hillshade/shaded DEM, coarse/latent boards and aligned height profiles are exported. These are useful review artifacts, not an automatic quality gate. There is no need to mandate every earlier suggested research-scale footprint merely to accept the experimental tooling.
- **Version/cache separation improved.** Macro geometry is versioned as `finite-geography-v2` with golden sample checks. The current production identity includes source content and numerical settings, so profile names alone do not permit silent reuse of incompatible cached worlds. Broad invalidation on server-only edits remains a disclosed efficiency cost.

## Provenance boundary and remaining limitations

The 32 NN arrays under `reference-b1r1` remain **historical, unattested**. The final report correctly refused source changes during the run. Do not rename those arrays into a new manifest or describe their count as a completed E1 gate. A fresh output directory and stable source snapshot are required for the final run. The exporter separately records its own SHA-256 in artifacts and the reporter SHA-256 in E1; preserve those together with the index and manifests when archiving the result.

The intended CLI loads the pinned checkpoint and actual configured runtime. The generic `build_manifest()` API still contains declarative checkpoint/conditioning defaults and can be called with arbitrary checkpoint paths or caller-supplied numerical data. The neural exporter records actual kwargs inside its execution description, but that is not a universal validator of arbitrary mutated in-memory models. Acceptance here is limited to the reviewed pinned-loader workflow; alternate checkpoints/settings require explicit provenance validation rather than assuming the defaults certify them.

The CPU lattice and nine tests establish useful unit, crop, seed and profile contracts. They do not establish faithful polar extrapolation, the five-field joint distribution, protected coastline topology, realistic ridges/basins, multiscale visual quality, or a performance improvement. Clipping can introduce saturated climate regions. A3's remaining flat-coast concerns remain open; no additional geometry change is required merely to record that failure honestly.

`natural` remains the default and nonzero natural worlds continue through the installed factory. A0 comparison passes the documented transformed-input tolerance; that is distinct from proving bitwise equality of every final NN crop against the original saved runtime. The clean multi-seed NN run, actual stage boards, protected-site assessment and human visual approval remain outstanding.

**Disposition:** accept the code corrections and experimental tools with these limits. E1 evidence stays pending until a clean source-bound corpus is produced and reviewed; no macro profile is approved as the new product baseline.
