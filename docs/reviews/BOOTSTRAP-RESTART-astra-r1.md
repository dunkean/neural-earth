# Bootstrap restart review — Astra r1

Date: 2026-10-07. Read-only implementation review; this review document is the only file written by the reviewer. No GPU, neural inference, browser interaction, or production source changes were performed.

## Result

No confirmed open P1/P2 issue remains in the source inspected at the end of this review. Two concrete P2 findings were reported during review and their fixes are present. This is a source/integration review, **not acceptance of visual quality, NN fidelity, 30 m detail, or navigation performance**. Source files were changing during the review; restart and final evidence must use the frozen implementation.

## Findings reported and fixes inspected

1. **P2 — Native provenance verification reused a cached identity.** Originally `verify_manifest_files()` obtained native identity through the cached `implementation_identity()`. Native Rust source, Cargo.lock, upstream core or executable changes after the first manifest could therefore escape the purported current-file verification. New uncached `verify_implementation_identity()` checks native source identity, Python bytes, ETOPO bytes and executable bytes; `terrain_manifest.py:163` calls it. New generation runs a private executable copy whose hash is checked against the frozen identity (`terrain_bootstrap.py:133`, `:148`, `:256`). These changes address the finding and the shared-build-target mutation risk. The new drift test is present in `test_terrain_bootstrap_native.py`; it was inspected, not independently rerun by this reviewer.

2. **P2 — Preview source resolution overstated geographic detail.** Originally terrestrial conditioning previews advertised a 7,680 m source resolution, although their persisted height raster is 1,024 × 512 across 40,000 × 20,000 km: **39,062.5 m per map axis**. The corrected physical report computes that raster spacing for terrestrial previews (`terrain_server.py:726`), retaining 7,680 m for learned coarse output. World metadata now exposes bootstrap raster spacing separately (`terrain_server.py:538`). This addresses the provenance/status error without changing runtime LOD arithmetic.

## Checks and positive observations

- Read the four `docs/TERRAIN_BOOTSTRAP_*` studies/contracts and the requested Python, Rust, browser, reference-export and test sources. No live `city_generator` code or method is used in the reviewed bootstrap. The exposed world profile list is Natural plus Gondwana, separated continents, Earthlike and archipelago; rejected Earth/A1–A4 recipes are not accepted by the runtime profile validator.
- The Rust bridge uses the pinned CPU `World::generate` atlas height, rather than the upstream viewer/sampler detail path. It records actual configuration, requested and selected u64 seed, deterministic candidate attempts, generator version, grid mapping and native topology. Python identity includes upstream/bridge source hashes, locked dependencies, executable hash, ETOPO digest and sampling conventions.
- Height is retained in metres through calibration and bilinear sampling. `BootstrapConditioning.__call__` applies the signed square root once. The normal non-import conditioning path invokes that factory directly; no second square-root transform was found. BIO1 receives one precipitation-dependent lapse adjustment, and preview transport reverses that adjustment once for its sea-level baseline. BIO4 uses actual source seasonality units.
- Sampling has a global origin, longitude wrapping and explicit polar clamping; window order/size does not recalibrate height or climate. Native reconstruction overlaps adjacent face interpolants and includes a direct edge/corner continuity test. The rendered world and NN remain a finite plane: periodic bootstrap longitude is not a claim of a periodic NN globe.
- Inspected all **35 existing bootstrap NPZ files** available during review. They included the 32 multi-seed QA worlds plus earlier cases. Applying `terrain_metrics()` and its four-neighbor, longitude-periodic, spherical-area components to the persisted signed raster met the relevant style thresholds in every inspected case. These were **pre-freeze caches**, with Python digest prefixes `6ba56c3f` or `2d83d915`; this does not certify the final implementation digest. Native topology uses eight neighbors, while that QA measure uses four; the agreement here is empirical, not equivalence of the definitions.
- Cache loads verify array shape, dtype, finiteness, SHA256, namespace and sign agreement. Persisted writes use atomic replacement. Runtime cache namespaces include the startup generator identity; coarse persistence uses full per-world manifests.

## Remaining limits and required final evidence

- Style acceptance occurs on native atlas topology before raster reconstruction. No failing raster was observed in the available batch, but final raster topology should remain part of the frozen-source QA report; accepting a native atlas does not mathematically guarantee every exported narrow connection or strait survives.
- `sign_preserved` means **signs at raster sample centres**. Independent nonlinear land/depth calibration followed by bilinear interpolation moves shoreline zero crossings relative to bilinear interpolation of the raw raster. A read-only calculation on pre-freeze seed 4,294,967,297 caches found maximum horizontal-edge zero-crossing movements of approximately 6.6 km Gondwana, 13.4 km continents, 10.4 km Earthlike and 7.8 km archipelago; median movements were approximately 1.9–4.0 km. This is a disclosed calibration limitation, not an additional blocking finding: the calibrated raster is the canonical provider. NN coastline comparisons must use that provider, as the QA coast-focus refinement already does, and must not interpret pixel-sign preservation as preservation of the original continuous coastline.
- The bounded twelve-candidate search can reject a seed. This review did not run a broad new seed search or establish a universal style-generation guarantee. Preserve explicit failures and the final morphology investigation results; do not silently fall back to a rejected style.
- Latitude-quantile climate is an approximation; it does not model circulation or joint climate statistics. The four climate channels are not periodic with bootstrap longitude, which is consistent with the explicitly finite-plane NN contract but should not be described as full spherical climate continuity.
- Parent-reported CPU tests are not repeated/certified here. Actual final NN outputs, coast/relief comparisons, decoded 30 m crops, LOD transitions, browser responsiveness and cold/warm timings still need their own frozen-identity evidence. Successful source review and coarse histograms cannot establish those outcomes.
