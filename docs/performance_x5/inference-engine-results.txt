KERNELS EXACTS

terrain_cuda_kernels.py compile des kernels BF16 par NVRTC12.8 livré avec Torch,
sans extension C++/MSVC, sur le stream Torch. Somme MP à deux entrées,
concaténation pondérée et SiLU des UNetBlock conservent les arrondis BF16
intermédiaires. Pas de contraction FMA. SiLU des embeddings EDM reste upstream.
CPU, entraînement, autres dtypes/strides/signatures restent dans la voie Torch.
Les modules CUDA sont conservés pour les graphes capturés, les allocations et
leur durée de vie restent gérées par Torch. Aucun checkpoint n'est modifié.

Avant publication du pack sur chaque GPU : tous les motifs BF16 finis pour
SiLU, probes somme à poids multiples et zéros signés, concat à canaux différents.
La compilation et ces contrôles se font avant la capture. Un échec de préparation
garde la référence et son motif dans le statut. Un échec de capture du wrapper
CudaGraphModel peut revenir à eager ; un échec persistant de lancement natif
se propage aussi dans cette voie. Configuration immuable par processus pour protéger
les modèles partagés et leurs graphes. TERRAIN_EXACT_KERNELS=0 désactive la voie
dans un processus neuf. L'identité persistante inclut le code et les réglages.
